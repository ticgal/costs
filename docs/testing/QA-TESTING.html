Costs plugin — QA acceptance checklist (5.0.0, GLPI 12)

Run every check on a GLPI 12.0 instance with the plugin installed and enabled. Fill in Result with OK or KO only; use Comments for the error message, a screenshot reference or a note on what went wrong.

Preparation: two sibling entities A and B under the root entity; a super-admin; a user with the Admin profile only in entity B (not recursive); a Technician in entity A; a Self-Service user in entity A.

Every check below writes only to the GLPI database of the test instance ([live write] where it creates or changes records). Nothing is sent outside GLPI.

Configuration

#CheckStepsExpectedResultComments
1Plugin configuration requires re-authenticationLog in as super-admin, go to Setup > Plugins and open the Costs configuration (or Setup > General > Costs tab).GLPI asks for the password again before showing the page, like the core configuration.
2[live write] Enable "Add task description on cost"After re-authenticating, enable the option and save.The option stays enabled after reloading the page.
3[live write] Entity cost settingsAdministration > Entities > A > Costs tab. Disable "Inheritance of the parent entity", set Fixed cost 5, Time cost 30, Auto billable ticket Yes, save.The values are kept after reloading; the per-profile section is shown below.

5[live write] Per-profile costIn entity A's Costs tab, add the Technician profile with Fixed cost 2 and Time cost 50.The row appears in the list; the Technician profile is no longer offered in the dropdown.
6[live write] Remove a per-profile costSelect the row with the checkbox, Actions > Delete permanently.The row disappears.

Permissions

#CheckStepsExpectedResultComments

14[live write] Requesters cannot make their ticket non-billableAs the Self-Service user create a ticket in entity A, then (as super-admin) check its Billable value.Billable = Yes (the entity default), whatever the requester sent.
15Technician without entity rightsAs the Technician, open Administration > Entities > A.No Costs tab; the entity costs cannot be changed.
16Entity isolationAs the Admin of entity B, open entity B and then try to reach entity A.Entity B's Costs tab works; entity A is not visible, and its costs cannot be changed.

Known limitations

  • The cost rate used for a task is the one of the technician's default profile, not the profile active when the task was closed.
  • Costs are only generated for ticket tasks (not change, problem or project tasks).
  • The "Costs Tech" report needs the separate reports plugin; without it the report URL answers "not found".
  • Fixed and time costs accept whole numbers only in the entity form (step of 1).
